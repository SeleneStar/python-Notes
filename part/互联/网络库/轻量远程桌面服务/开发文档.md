# 项目开发文档（基于实际代码与功能）

## 1. 概述
- 这是一个基于 aiohttp 的轻量远程桌面服务，集成屏幕 MJPEG 流和 WebSocket 输入控制。
- 根路径“/”返回页面：优先加载同目录的 web_client.html；若不存在则返回内置页面（包含移动端触控支持与透明 overlay，避免手机长按弹出系统图片菜单）。
- 实际端口默认 50080；访问需携带 token（默认 123456）。

## 2. 运行环境与依赖
- 操作系统：Windows（已在 Windows 10 上验证；需桌面会话权限）
- Python：3.9+ 推荐
- 依赖库：
  - aiohttp
  - Pillow
  - mss
  - pynput
- 安装依赖（PowerShell）：
  ```
  pip install aiohttp pillow mss pynput
  ```

## 3. 配置（实际代码）
- 默认值（web_server.py 顶部）：
  - HTTP_PORT = 50080
  - PASSWORD = "123456"
  - TARGET_FPS = 15
  - JPEG_QUALITY = 60
  - DOWNSCALE = 0.8
- 环境变量覆盖（已在代码中读取）：
  - 端口：`$env:REMOTE_HTTP_PORT`
  - 访问令牌：`$env:REMOTE_PASSWORD`

参数含义：
- TARGET_FPS：目标帧率（MJPEG 推送频率）
- JPEG_QUALITY：JPEG 编码质量（10~95）
- DOWNSCALE：图像缩放比例（0.3~1.0）；越小带宽越低

## 4. 启动与访问（实际端口）
- 启动示例（PowerShell）：
  ```
  $env:REMOTE_HTTP_PORT=50080; $env:REMOTE_PASSWORD="123456"; python web_server.py
  ```
- 控制台提示：
  ```
  [Web] 打开浏览器访问: http://<被控端IP>:50080/?token=123456
  ```
- 浏览器访问：
  - 本机：`http://localhost:50080/?token=123456`
  - 局域网：`http://<被控端IP>:50080/?token=123456`
- 必须携带 `?token=...`，否则返回 403。

## 5. 接口说明（真实路由）
- GET `/`（参数：token）
  - 成功：返回页面（优先 web_client.html；否则内置页面）
  - 错误：403（令牌错误）、500（页面加载异常，已做异常处理）
- GET `/stream`（参数：token）
  - 返回 MJPEG 流，`Content-Type: multipart/x-mixed-replace; boundary=--frame`
  - 每帧格式：
    ```
    --frame\r\n
    Content-Type: image/jpeg\r\n
    Content-Length: <N>\r\n
    \r\n
    <JPEG数据>\r\n
    ```
- GET `/screen`（参数：token）
  - 返回：
    ```
    {"ok": true, "width": <int>, "height": <int>, "fps": <int>}
    ```
- WS `/ws`（参数：token）
  - 服务端首次消息：
    ```
    {"type":"hello","width":<int>,"height":<int>}
    ```
  - 心跳：客户端发 `{"type":"ping"}` → 服务端回 `{"type":"pong"}`
  - 鼠标消息（客户端→服务端）：
    ```
    {"type":"mouse","act":"move|down|up|double","btn":"left|right|middle","nx":0..1,"ny":0..1}
    ```
    说明：
    - nx, ny：基于图像元素的相对坐标（0..1）
    - move：移动到坐标
    - down/up：按下/抬起指定按钮
    - double：服务端执行双击（两次 press/release，间隔约 50ms）
  - 键盘消息（客户端→服务端）：
    ```
    {"type":"key","act":"down|up","key":"enter"|"esc"|"tab"|...或字符}
    ```
    特殊键映射：enter, esc, tab, backspace, delete, left, right, up, down, shift, ctrl, alt, meta(cmd)

## 6. 内置前端行为（与当前代码一致）
- 页面结构：`img#screen` 显示 MJPEG；`div#overlay` 透明覆盖在其上作为交互层。
- 事件绑定：所有鼠标与触控事件都绑定在 `overlay` 上，避免移动端长按触发系统图片菜单。
- 桌面浏览器：
  - 右键：拦截 `contextmenu`，发送一次右键 `down+up`
  - 双击：发送 `act="double"`
  - 移动/按下/抬起：按坐标归一化后发送
- 移动端触控：
  - 短按：左键单击（down+up）
  - 双击：300ms 内二次轻触 → `double`
  - 长按：约 500ms → 右键单击（down+up）
  - 拖动：touchmove → move
- 禁用图片默认行为：设置 `webkitTouchCallout/userSelect` 为 `none`，并将交互转移到 overlay。

## 7. 服务端核心逻辑
- `capture_loop()`
  - 使用 `mss` 抓取 `monitors[1]`（主屏），按 `DOWNSCALE` 缩放，`Pillow` 编码为 JPEG
  - 控制采集节奏：`TARGET_FPS`
  - 最新帧存入 `latest_jpeg`（加锁保护）
- `handle_index()`
  - 校验 token；尝试读取 `web_client.html`；不存在则返回内置 HTML（含 overlay + 事件脚本）
  - 返回 `content_type="text/html"`（不带 charset）
- `handle_stream()`
  - 输出 MJPEG multipart 流，循环写入 `latest_jpeg`
- `handle_screen()`
  - 返回屏幕宽高与目标帧率
- `handle_ws()`
  - 解析消息：
    - 鼠标：`move/down/up/double`（双击已实现）
    - 键盘：特殊映射或字符按压/释放
    - 心跳：`ping` → `pong`
- `main()`
  - 启动采集线程，注册路由，运行 aiohttp 应用

## 8. 常见问题与排查
- 403 Forbidden：
  - 未携带或令牌不匹配。请使用 `/?token=你的令牌`。
- 500 Internal Server Error：
  - 加载自定义 `web_client.html` 异常；可先删除该文件以使用内置页面。
- 无法访问：
  - 确认服务运行与端口监听：
    ```
    netstat -ano | findstr :50080
    Test-NetConnection -ComputerName localhost -Port 50080
    ```
  - 局域网访问需放行防火墙 `50080/TCP`
- 移动端长按弹系统菜单：
  - 已通过 `overlay` 层与禁用 `touch callout` 处理；若仍出现，清缓存或更换浏览器测试。
- 右键/双击无效：
  - 先单击使目标窗口获得焦点；少数应用对注入事件响应有限。

## 9. 安全建议
- 使用强令牌：设置 `$env:REMOTE_PASSWORD` 为复杂随机字符串。
- 仅在可信网络内使用；不建议直接暴露公网。公网场景建议配合网关与 HTTPS 反代（如 Nginx）。
- 确保运行在具有桌面会话的环境；`pynput` 在锁屏或无交互会话下可能不可用。

## 10. 性能与带宽优化
- 降低 `TARGET_FPS` 与 `DOWNSCALE` 可显著降低带宽。
- `JPEG_QUALITY` 50~70 通常平衡画质与码率。
- 局域网可提高帧率与质量；蜂窝或公网建议降低。

## 11. 自定义前端（可选）
- 将 `web_client.html` 放在同目录即可覆盖内置页面。
- 事件与坐标规范：
  - 使用元素 `getBoundingClientRect` 将 `clientX/Y` 映射到 `nx/ny`（0..1）
  - 按上述 WS 消息格式发送到 `/ws`
